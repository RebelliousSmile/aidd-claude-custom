## Top actions

1. **Fermer le chemin `--contract`** (🔴 + 🟡 traversée). Les deux se corrigent dans la même fonction, en une dizaine de lignes, et se prouvent avec les deux fixtures déjà écrites. C'est le seul endroit du générateur où une donnée non produite par lui entre dans le document sans être regardée.
2. **Couper le registre de `Object.prototype`** (🟡 lookup). Une ligne, atteignable par URL, et c'est exactement l'état « pas de diagnostic à l'écran » que la passe de durcissement du 05/08 prétendait avoir supprimé.
3. **Aligner `js_literal` sur ce qu'il promet** (🟢). Sans urgence, mais la docstring ment aujourd'hui, ce qui est le vrai risque : quelqu'un s'y fiera pour une entrée moins contrainte que les clés de page.
