# Clinic booking brief

- Product: appointment booking for a community clinic
- Audience: patients using mobile devices, including low-vision users
- Platform: responsive web
- Personality: calm, trustworthy, direct
- Theme: light-first with a documented dark theme
- Colour direction: blue primary, neutral surfaces, status colours must not rely on colour alone
- Accessibility: WCAG AA, keyboard and visible-focus support
- Icon style: simple outlined icons paired with text labels
